# PR08: local semantic memory in pgvector

Lesson: Retrieval turns stored records into useful context.

Index memory embeds three short guidance records and up to 100 validated outcome comparisons.
Ollama's local nomic-embed-text supplies 768-dimensional vectors; model digest/version is
stored with each record. Exact cosine search returns up to five candidates with provenance.
Real and synthetic outcomes stay separate; invalid, expired, and other-model records are excluded.
Indexing the same content/model again is idempotent. No second vector database is introduced.

Verification: `make verify` passed (26 tests + 8 Playwright checks); uses an explicit deterministic test double, not claimed
semantic-model evidence. Checks include vector round trip, eligibility, repeated indexing,
and Playwright index/search. A separate Playwright check used actual local Ollama: “protect the battery from running too
low” ranked reserve guidance first at cosine 0.618. Model digest is refreshed per operation.
Migration risk LOW: one additive vector table. Retain it for rollback; no ANN index is needed.

Optional local check:
