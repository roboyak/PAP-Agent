# PR14: switch local and cloud model providers

Lesson: Change the model provider at one boundary while preserving inputs, validation, and budgets.

`AGENT_BACKEND=ollama|openai|anthropic` and `AGENT_MODEL` select all model-driven roles.
Ollama remains the default. Cloud calls use official LangChain integrations, native structured
output, no tools, zero retries, and the existing 45-second/768-token bounds. Provider/model
labels are persisted in model records and comparison results. Embeddings remain local.

API keys come from ignored `.env` or shell settings. Readiness reports key presence only;
cloud account access is checked on a call. Cloud selection sends the bounded model context
to that provider. Audit records contain no keys or raw SDK errors. Numerical authority,
MCP, database schema and graph routing are unchanged.

Verification: the real OpenAI/Anthropic SDK and `create_agent` paths pass with fake HTTP for
valid JSON, invalid numerical fields, and API failure without retries. `make verify` passed
44 tests and 12 Chromium Playwright checks. Independent PR, safety, agent-boundary, test,
workflow, architecture and documentation reviews found no remaining major issues.
No live cloud API call or quality comparison
was performed because neither API key was configured.

Optional human walkthrough (configure the corresponding key locally first):

```bash
AGENT_BACKEND=openai AGENT_MODEL=gpt-4.1-mini make run
# Stop with Ctrl-C, then switch:
AGENT_BACKEND=anthropic AGENT_MODEL=claude-haiku-4-5-20251001 make run
```

In each session, open http://127.0.0.1:8000, Check service, Load sunny fixture, then Compare
agent off / on. Context and Subagent show provider/model, calls, time, usage and validated
output. Keep feedback/memory unchanged between providers. Each pair shares its own snapshot;
separate provider runs are a manual comparison of the fixed fixture, not a quality benchmark.
An unavailable/invalid model produces a recorded failure; it cannot change calculated power.

Rollback: `AGENT_BACKEND=ollama AGENT_MODEL=gemma3:4b make run` after stopping the service,
or revert this PR. Existing records remain usable. The capstone exports remain pinned to
their documented baseline until the next artifact refresh.
