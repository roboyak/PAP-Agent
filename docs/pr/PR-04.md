# PR04: deterministic solar-surplus profile

Lesson: Deterministic code owns arithmetic and reserve checks.

Calculate PAP now builds twelve hourly intervals from measured solar/load and synthetic
weather. Extra power is solar surplus; kWh integrates interval duration. Battery discharge
budget is zero. T6 withholds at/below the fixed 305.2 V MySolArk floor, which the user maps
to their ~30% SOC reserve. No SOC curve or equipment rating is inferred.

Forecasts, calculations, and validation decisions persist with evidence IDs. Repeated sunny
runs yield 10.6 kWh. The UI shows the result and source/tool records.

Verification: `make verify` passed (21 tests + 5 Playwright checks). Tests cover arithmetic, reserve gating, persistence,
T6 candidate rejection, repeated browser calculations, and a failed live-source switch.
A separate actual-MySolArk Playwright run produced 0.835 kW additional power with the 305.2 V floor.
Migration risk LOW: additive calculation table and nullable unconfigured equipment cap.
Rollback: retain calculation records; nullable caps deliberately stay nullable on downgrade.
