# PR11: bounded generator and critic agents

Lesson: Models propose and critique; Python controls selection and limits.

The selective search now calls isolated LangChain `create_agent` generator and critic roles
using local Gemma 3. Each has structured output, no tools, the same validated evidence,
and concise summaries. Only hard-check survivors reach the critic. Its five rubric fields
sum to at most 100; deterministic beam selection uses grounding/uncertainty for close ties.
The existing branch/beam/one-revision limits remain unchanged.

Every attempted call reserves a durable record before contacting Ollama. The shared episode
budget counts generator, critic and optional interpretation together, including interrupted
attempts. No automatic retries. Invalid output or missing scores can withhold publication;
no agent controls voltage reserve, numerical availability or T6. The environment flag still
controls only the optional third interpretation role. Context/Subagent expose real inputs,
response schemas, call counts, usage and validated output; Trace keeps branch decisions.

Verification: `make verify` passed (37 tests + 10 Playwright checks), including the
two-role/three-role browser inspection and shared reserved-call budget. Actual MySolArk/Ollama Playwright pair
preserved calculated intervals. Two roles used four calls / 53,035 ms and published valid;
three roles used six calls / 70,223 ms and selected withhold. Both terminated within the
bounds with no browser errors. Model rankings/guidance differed; this observation does
not establish a benefit from the third role. The flag remains off by default.
No schema migration. Fake models exercise the same create_agent graph in required tests.
