# PR03: live MySolArk evidence through read-only MCP

Lesson: MCP connects data; T3 decides whether it is usable.

Two discovered MCP tools return the latest persisted voltage/PV/load scrape and synthetic
weather. Real timestamps and observation age are visible. T3 applies a five-minute freshness
limit before storing usable typed evidence. The UI shows tool arguments, results, and timing.
Source queries run read-only; device identifiers, raw JSON, SOC, and credentials are excluded.

Verification: `make verify` passed (17 tests + 4 Playwright checks), including real stdio
MCP → API → browser with an isolated source-shaped database. A separate Playwright check
against actual MySolArk showed 393 V, 1.63 kW PV, 0.771 kW load, and a 72.4-second-old scrape.
Migration risk LOW: one additive evidence table. Retain it for application rollback.

Optional local check:
```bash
make verify
make dev
```
Open http://127.0.0.1:8000, click Read MySolArk now, inspect Tools and Context.
When the scrape is less than five minutes old, expect real voltage/PV/load, its UTC timestamp
and age, and synthetic weather. Older readings are withheld and remain inspectable in Trace.
`SOURCE_DATABASE_DSN` configures the local source connection. No human testing is claimed.
