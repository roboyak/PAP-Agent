# PR10: selective bounded search

Lesson: Structured search is graph control, not a longer prompt.

Routine runs remain linear. Validated outcome feedback above the existing demo threshold
of 0.25 kW mean solar overestimation opens the persistence/refresh/withhold alternatives.
The assessment and top-three retrieval are captured before the search. A child LangGraph
owns generation, hard pruning, critique, beam selection and final deterministic submission.
It caps three children per parent, beam two, one refinement, submission depth three and
an eight-model-call budget shared with interpretation. PR10's generator/critic are explicit
zero-model-call fixtures; PR11 replaces those two interfaces.

Search changes confidence/guidance or withholds publication; it cannot change the fixed
voltage floor, forecast arithmetic or power intervals. No acceptable branch withholds.
Branch IDs, parents, evidence, hard-check results, rubric scores and stop reasons live in
canonical audit records. Scores are not probabilities. Trace shows linear/selective_tot.
