# PR12: command-line MVP runtime

Lesson: A small agent service needs visible readiness and explicit process boundaries.

Adds native bootstrap/run/verify scripts, a CLI demo, and test/development/macmini-replay
profiles. `/health/live` stays independent of dependencies; `/health/ready` checks migration
head, pgvector query, a rolled-back audit-table write, graph/checkpointer, MCP/source freshness
and local model availability without saving probe evidence. Health shows those results.
Comparison now refreshes source/context/tool panels with the exact paired evidence.

Optional LangSmith exports only an allowlisted API-run summary after publication. Automatic
SDK tracing stays disabled; credentials/prompts/telemetry/memory never enter that export,
and export failure is non-fatal. No remote export was performed. Foreground terminal commands
are the deliberately small process strategy; no Docker or login daemon was added.

Verification: `make verify-mac` passed (40 tests + 10 Playwright checks plus CLI demo).
The CLI produced a stale-data rejection and identical-power two/three-call comparison
using explicitly labeled doubles. Final `make verify` also passed after the .env export
configuration fix. Native bootstrap and make run passed. Actual MySolArk/Ollama Playwright
returned readiness 200, completed a withheld decision with five bounded model calls,
and verified all six panels with no browser errors. Local source evidence was fresh at acquisition.
No schema migration. All read-only reviews passed; the .env credentials/project finding was fixed. The runbook and final architecture state the
fixed 305.2 V floor, synthetic weather, zero battery discharge, unknown live cap and advisory
model-quality limits. All twelve teaching increments are documented; no release tag created.

Optional local check:
```bash
make verify-mac
make run
```
Open http://127.0.0.1:8000, Check service, then Run PAP. Inspect all six tabs and compare agents
when desired. Ctrl-C stops the service; `make db-down` stops PAP's separate database and preserves
its data. No human testing claimed.
