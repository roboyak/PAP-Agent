# PR09: grounded optional interpretation and paired comparison

Lesson: Retrieval selects evidence; a bounded agent interprets it.

`ENABLE_INTERPRETATION_AGENT=false` keeps the deterministic path as the default. Enabling
it adds retrieve → interpret → validate nodes. Five cosine candidates pass version/score
checks, exact-content deduplication and a top-three limit. The isolated `create_agent`
call uses local Gemma 3, structured JSON and zero tools. Accepted advice can lower confidence
and recommend a refresh; it cannot change power, voltage policy or T6. Failed/malformed
attempts lower confidence and are not retried. Inputs, citations, results and timing are
stored in additive `reasoning_records`, separate from PostgreSQL checkpoints.

The comparison button runs interpretation off/on on the same source evidence. It reports
calls and latency, not a quality probability. Context, Memory, Subagent and Trace expose
actual inputs and validated outputs; no private chain-of-thought is stored.

Verification: `make verify` passed (30 tests + 9 Playwright checks). Actual MySolArk/Ollama
Playwright comparison preserved every interval: 25 ms / zero model calls off versus
8,813 ms / one call on. This is one warm paired observation. An initial explanation
misstated a fact; explicit context and a shorter prompt improved the observed output.
Schema/citation checks do not prove the truth of free-text advice. All read-only reviews passed.
Migration risk LOW: one additive audit table. Keep the table when rolling back application code.
